About The API

Explore our Movie API

Our Movie API is built to help users browse a curated collection of films through a simple and responsive interface. It provides a sorted listing of movie entries along with a separate endpoint for viewing detailed information about each title.

How To Use Our API

Simple and easy to connect

Our website fetches data from a custom API to display movies in two categories: Horror and Comedy. Each movie includes its image, title, director, and genre, allowing content to load dynamically and stay easy to update.
